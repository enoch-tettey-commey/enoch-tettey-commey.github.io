PUBLISHING TO YOUR EXISTING GITHUB PAGES REPOSITORY
1. Open https://github.com/enoch-tettey-commey/enoch-tettey-commey.github.io
2. Before replacing files, download a ZIP of the current repository as a backup (Code > Download ZIP).
3. Upload/replace index.html, styles.css, script.js, README.txt, and the assets/ and projects/ folders at the repository root on the main branch.
4. Commit the changes. Keep index.html at the root because Pages is configured to publish from the root folder.
5. Wait a few minutes, then open https://enoch-tettey-commey.github.io/ and hard refresh (Ctrl+F5).
6. Test the email link, CV PDF link, and Excel workbook download.

IMPORTANT
- The included CV PDF was exported from the tailored Care Associate CV and may not be the best version for every role. Review it before publishing. Replace it with a current general-purpose CV if preferred.
- The inventory tracker uses fictional example data; it is a portfolio demonstration, not an employer's real data.
- GitHub Pages repositories are public websites. Do not upload private information, ID numbers, or confidential employer data.
