COMMey ENOCH TETTEY — PORTFOLIO WEBSITE

Files:
- index.html: website content
- styles.css: responsive layout and design
- script.js: mobile navigation and current year

HOW TO VIEW:
1. Extract the ZIP file.
2. Open index.html in a web browser.

BEFORE PUBLISHING:
1. Replace “Replace with your professional email” in index.html with your real professional email.
2. Verify all role titles, dates, and descriptions against your final CV.
3. Add your CV file and a real download link only when you have selected the final version.
4. Build the listed projects before describing them as completed. They are explicitly marked as planned projects in this starter portfolio.
5. Review any personal details before publishing. This starter site intentionally does not include phone number, relationship status, religion, or a portrait.
6. For online publishing, upload the folder to a static hosting service such as GitHub Pages or Netlify.

The site uses Google Fonts when internet access is available and falls back to system fonts otherwise.
